# 外链与品牌信号计划（机场 Pro）

目标：让 Bing 认识“机场 Pro / jichangpro.blog”这个品牌，并获得来自相关网站的真实链接。
原则：只做真实、有用的曝光；**不买外链、不群发垃圾评论、不做站群**——这些会被 Bing 判定为操纵排名，反而降权。

## 一、自有渠道（第 1 周就做，最可控）

| 渠道 | 做法 | 作用 |
| --- | --- | --- |
| Telegram 频道 | 建立“机场 Pro”公开频道，每次更新价格、评测、教程都发一条带链接的消息 | 品牌搜索量、稳定的回访流量 |
| GitHub 仓库 | 建一个公开仓库（如 `jichangpro/jichang-tuijian`），README 放机场价格对比表、选购要点，并链接回本站对应页面；每月更新一次 | 竞品普遍在用，GitHub 权重高、Bing 收录快 |
| Bing Webmaster + IndexNow | 上线即提交 sitemap，开启 Cloudflare Crawler Hints | 新页面更快被收录 |

> GitHub README 模板见 `docs/github-readme-template.md`，内容由本站数据生成，更新价格后重新生成即可。

## 二、内容型外链（第 1–3 个月）

1. **可被引用的数据页**：本站的 [机场综合对比表](/compare/)、[每 GB 成本对比](/value/)、[机场优惠码](/coupons/) 都是别人愿意引用的“数据资产”。在分享时优先链接这些页面。
2. **问答平台**：在知乎、V2EX、Reddit（r/China_irl 等）、Telegram 群中**回答真实问题**（例如“IPLC 和 IEPL 有什么区别”“机场年付值不值”），在回答中自然引用本站对应教程。每周 3–5 条高质量回答，比 100 条广告有效。
3. **投稿 / 互换**：联系做科学上网教程、VPS 测评的独立博客，提供本站的测试数据或教程供引用，或在双方的“友情链接 / 资源推荐”中互链（只与内容相关、质量正常的网站互换）。
4. **开源社区**：Clash Verge Rev、v2rayN 等项目的讨论区、Wiki 中，有人询问配置问题时可以引用本站对应教程（遵守各社区规则，不发广告）。

## 三、品牌信号（持续）

- 全站统一名称“机场 Pro”和域名，Telegram、GitHub 等资料页都写同样的简介和网址（建立频道或 GitHub 后，可把链接加入 `src/utils/schema.ts` 的 `sameAs`）。
- 鼓励老用户直接搜索“机场 Pro”访问（频道置顶网址、评测页底部提醒收藏）。
- 每月固定更新一次价格与“最后更新”日期，形成稳定的更新频率。

## 四、要避免的做法

- 购买“高权重外链包”、PBN、站群；
- 在论坛、博客评论区大量留链接；
- 用多个域名复制同样的内容；
- 隐藏文字、关键词堆砌。

## 五、每月检查

在 Bing Webmaster Tools → Backlinks 查看：
- 新增引用域名数（目标：每月 +5～10 个真实域名）；
- 品牌词“机场 Pro”的曝光与点击；
- 哪些外链带来了点击，加大在对应平台的投入。
