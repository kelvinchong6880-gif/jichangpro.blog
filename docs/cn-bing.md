# 国内版 Bing（cn.bing.com）可见性：检测与应对

## 已观察到的情况（2026-10-02）
- 从马来西亚访问 cn.bing.com 会被自动跳转到 www.bing.com（mkt=zh-CN）。
- 在 zh-CN 市场搜索“机场推荐”，结果只有约 52 条，且大多与查询无关（知乎问答等），说明该关键词在 zh-CN 市场**很可能被过滤或大幅限制**。
- 结论：国内用户在 cn.bing.com 搜“机场推荐”时，任何翻墙机场网站都可能不显示；本站能否出现需要上线后用真实数据确认。

## 上线后的检测方法
1. **Bing Webmaster Tools → 搜索性能**：按“国家/地区”筛选，分别查看中国大陆、香港、台湾、马来西亚、新加坡、美国等地区的曝光。中国大陆曝光长期为 0 而其他地区正常，即可判断被过滤。
2. **收录检查**：在 www.bing.com 搜 `site:jichangpro.blog`，确认页面已收录。
3. **请国内朋友协助**：用国内网络打开 cn.bing.com，分别搜“机场推荐”“机场 Pro”“jichangpro”，截图记录。
4. **访问性检查**：用 17ce、boce 等国内拨测工具检查 jichangpro.blog 在国内各地的访问情况。如果国内无法访问，Bing 中国区也可能降低展示。

## 应对思路
- **以国际版 Bing 为主要目标**：大量国内用户在翻墙后使用 www.bing.com 或 Google，这部分流量不受国内版过滤影响。主关键词的排名目标以 www.bing.com（zh-CN / zh-HK）为准。
- **同时布局 Google**：同样的内容在 Google 也有排名机会，提交 Google Search Console 成本很低。
- **品牌词与长尾词**：即使主关键词被过滤，“机场 Pro”“Sogo 云评测”“Clash Verge Rev 教程”这类词往往仍有展示，能带来稳定流量。
- **站外渠道**：Telegram 频道、GitHub 等不依赖搜索引擎的渠道，见 `docs/backlink-plan.md`。
- **域名可访问性**：如国内无法访问，可考虑为国内用户准备备用访问域名，并在 Telegram 频道公布。

## 不建议的做法
- 为了绕过过滤而大量使用谐音、拼音替换关键词：会让内容可读性变差，也可能被视为操纵排名。
